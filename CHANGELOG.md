# Changelog

## 0.6.0

- New interface for adding music, managing the library, configuring stations, and sharing/exporting packs.
- Added multi-file, folder, and drag-and-drop importing.
- Added automatic preparation using the recommended compression profile.
- Added a persistent queue with stop/resume support.
- Added retry for failed items only.
- Added exact-duplicate skipping and reuse of previous conversions.
- Added one catalog backup per processing batch and per-track progress saving.
- Added import of individual YouTube links with verified external tools and conversion to the game format.
- Added audio preview, accent-insensitive search, metadata editing, and independent export.
- Added stored size information so the Manager does not need to scan or decode the full audio library when opened.
- Existing projects are preserved.
- No changes are required to RSF Vehicle Radio Base or the official music pack for this Manager update.
